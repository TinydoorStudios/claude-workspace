# Save a session (and back it up to USB)

Two buttons, two different jobs.

**Files > Save Session** overwrites the file you loaded, in place. It's the quick save. There is no undo.

**Files > Save As New File** writes a new file. Use it at the start of a show day so you always have last week's version untouched.

![Files > Save As New File](/figures/q2-save-as.png)
*Files > Save As New File — Quantum 2 offline software, V22.*

1. Files > **Save As New File**.
2. Choose **Internal** or **Removable**, then the folder. *new folder* / *rename folder* are on the right.
3. Touch the file name box and type a name. Touching an existing name in the list selects it, and Save will then overwrite that file after a warning.
4. Add a description; it shows up in the Load panel later.
5. Press **Save**. A pop-up confirms where it went.

![Save As New File](/figures/ref-p079-1.png)
*Manual figure: Save As New File panel, Reference 2.2.5.*

## Copy sessions to a USB stick

The Load and Save panels both have **Set backup** and **Copy backup** on the right.

1. Plug a USB drive into the console. *Copy backup* stays greyed out until the drive is seen.
2. Press **Set backup**, then touch each session you want. An asterisk appears in the **B** column.
3. Press **Copy backup** and confirm. The files copy to (or from) the removable drive.

## Autosave

Options > **Console** > *Auto-Save Recovery Session* writes the active `.ses` on a timer you set with the pot beside it. Turn it on for a show. It saves over the current file, so do a Save As first if you want a clean starting copy.

## Startup session

Options > Console also has *Load startup session on start-up* and *Save startup session on quit*. With both on, the desk comes back exactly where you left it. With them off, it boots to the default state.

Manual: [Reference 2.2 Files Menu](/reference/2-2-files-menu), [2.5.9 Options > Console](/reference/2-5-options).
