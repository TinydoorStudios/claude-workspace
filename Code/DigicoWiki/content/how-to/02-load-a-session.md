# Load a session

Sessions are `.ses` files. The console keeps its own in `D:\Projects`; a USB stick shows up as *Removable*.

1. Master screen > **Files** > **Load Session**.
2. Top left: pick **Internal** (D:\Projects) or **Removable** (USB). Expand folders with the **+**.
3. Touch the session in the middle list. The columns tell you when it was saved, its description, and how many inputs, auxes, groups and matrix channels it has, which is a quick way to spot the wrong file.
4. Press **Load** (bottom right). *Cancel* backs out.

![Load Session panel](/figures/ref-p076-1.png)

Once loaded, the Information Bar on the Master screen shows the session name. After you change anything, the *File:* line only shows the folder, not the filename, so don't rely on it to tell you which file you're on.

## Partial load

Select a session and press **Partial Load** (top right) to pull in only parts of it: ranges of input channels, matrix ins/outs, graphic EQs, banks and layout, presets, macros, and either *Replace Snapshots* or *Add Snapshots*. Handy for lifting a band's channels out of last week's file without losing today's system EQ.

![Partial load](/figures/ref-p077-1.png)

## Templates

Files > **Templates** lists sessions stored in `D:\Templates`. Load one the same way. To make a template from the current session, use *Save as template* in the Save As New File panel; later quick saves go to the sessions folder, not back into the template.

## Keep old presets

The *keep old presets* button on the Load panel adds the console's existing presets to the incoming session. Off, and they're cleared on load.
