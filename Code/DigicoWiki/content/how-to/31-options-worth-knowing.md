# Options worth knowing

Master screen > **Options**. Ten tabs; purple = on. These are the ones that change how the desk feels.

![Options panel](/figures/q2-options.png)
*Options panel — Quantum 2 offline software, V22.*

## Surface

- **Auto expand EQ / dynamics** and the *auto-expand time* pot: the panel pops open when you turn an encoder and closes after n seconds. *Auto-Expand Exclude Off* stops it popping when you switch a module off.
- **Large LCD names** shows channel names larger on the LCDs (with gain and solo bus, or name only).
- **Auto-revert LCD menu to solo** and its timer.
- **Panning type 1 / 2** (2 is the newer sine/cosine law; global).
- **2nd function auto-cancel** with a timer.
- **Round to whole dBs** rounds fractional dB values to the nearest integer.

![Options > Surface](/figures/ref-p111-1.png)
*Options > Surface — Reference Manual, p.111.*

## Faders

- **Fader touch assigns channel**: touching a fader assigns the channel to the worksurface controls. Off by default because a brush assigns the wrong channel.
- **0 dB detent** on inputs / outputs / graphics / CGs.
- **Fader touch control** Free vs Protected (a protected fader won't move without a touch).
- **Fader response during snapshot recall** Standard / Fast.
- **Set spill direction** L Vert / R Vert / Horiz.

## Solo

Covered in [Solo](/how-to/12-solo-pfl-afl-and-headphones). V22 adds *Aux to Faders includes Group*.

## Console

- **Load startup session / Save startup session / Auto-save** (see [Save a session](/how-to/03-save-a-session)).
- **Enable External Waves** and Legacy/ProLink mode for SuperRack (restart required). See [DMI-Waves](/hardware/07-dmi-waves).
- **Enable Console Network** for mirroring (restart required).
- **Enable Fourier Integration** (not fitted here).

## Meters

Attack/release rates, peak hold, overs hold (0 = infinite hold until cleared), PPM presets, and the **meter point** per channel type: pre-trim, post-trim (default for inputs), pre-fader, post-fader (default for outputs). These affect the surface meters, not the on-screen ones.

## Status

Turns the Status display and system alerts on or off, and **Signal Overs auto-open**: when anything clips, the Signal Overs panel opens and touching an entry brings that channel to the surface.

## Brightness, Delays, Disable, Gangs

Brightness pots for screens, LEDs and bridge. Delay units (seconds, feet, metres, bpm, frames). Disable lets you switch off surface buttons you don't want touched. Gangs sets what each channel type shares in a gang.
