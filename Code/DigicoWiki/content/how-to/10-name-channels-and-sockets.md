# Name channels and sockets

Two kinds of names. **Socket names** live in Audio I/O and follow the physical input ("Stage Rack: Mic 3"). **Channel names** live on the channel and, by default, copy the socket name until you type something.

## Channel names, one at a time

Touch the white name box in Channel Setup (top of the strip) or the Output panel. The on-screen keyboard has cut/copy/paste, arrows, **OK** and **CAN**. **Next** saves and jumps to the following channel, which is the fast way to name a bank.

The button beside the name box opens the **Channel Name** word list: touch words (Kick, Snare, Vox…) to build a name without typing; **Custom** stores your own words.

## Channel names, in bulk

![Layout > Channel List with Edit on](/figures/q2-channel-list.png)
*Layout > Channel List — Quantum 2 offline software, V22.*

Layout > **Channel List** > **Edit** on. Touch a channel's name and use the keyboard up/down arrows to run down the list.

## Socket and card names

Setup > Audio I/O > select the port > **Cards & Sockets**. Touch the **Group Name** (card) or **Socket Name** box. **auto-name** labels a run of sockets with the same word and an incrementing number: set how many with the numeric display, then press auto-name. This is what KLANG expects (sockets named KLANG 1, KLANG 2…).

## Fader layer names

Layout > Fader Banks lets you type a name for each fader layer on the Q225; it shows on the layer LCDs.
