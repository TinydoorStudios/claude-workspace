# 3.3 System Information

*Quantum Home — manual pages 60–61*

Opens a window displaying general information about the system:

- 

General:

o PC Name: name of the console PC – the factory default name should contain the serial number of the console. o IP Address: static IP address of the console PC. o App Version: version number of the Quantum 2 application. o Home Version: version number of Quantum Home. o System Version: version number of the overall system.

- 

Disks:

o C Drive: amount of free disk space on the C:\ drive. o D Drive: amount of free disk space on the D:\ drive. o Memory: amount of RAM on the console PC.

- 

BIOS:

o BIOS: version number of the console PC’s BIOS. o Firmware: version number of the console PC’s board controller firmware.

- 

Save to File: click to save the system information to a text file. The saved file also contains the “locked/unlocked” state of the PC and a timestamp.
