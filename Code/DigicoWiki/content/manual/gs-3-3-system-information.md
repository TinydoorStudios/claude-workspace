# 3.3 System Information

*Quantum Home — manual page 60*

Opens a window displaying general information about the system:

- **General:**
  - **PC Name:** name of the console PC — the factory default name should contain the serial number of the console.
  - **IP Address:** static IP address of the console PC.
  - **App Version:** version number of the Quantum 2 application.
  - **Home Version:** version number of Quantum Home.
  - **System Version:** version number of the overall system.
- **Disks:**
  - **C Drive:** amount of free disk space on the C:\ drive.
  - **D Drive:** amount of free disk space on the D:\ drive.
  - **Memory:** amount of RAM on the console PC.
- **BIOS:**
  - **BIOS:** version number of the console PC's BIOS.
  - **Firmware:** version number of the console PC's board controller firmware.
- **Save to File:** click to save the system information to a text file. The saved file also contains the "locked/unlocked" state of the PC and a timestamp.
