# 6.9 DMI AVB

*Chapter 6: DMI Cards — manual pages 242–243*

![DMI-AVB (Milan) card rear panel, Primary and Secondary RJ45 ports](/figures/ref-p242-2.png)

This Milan Certified card provides 64 input and 64 output channels at both 48kHz & 96kHz.

There are three sample rate modes, 48kHz, 96kHz and Mixed mode which allows a 96KHz device to share AVB streams with other devices set to 48KHz but this will require additional configuration.

Consoles with DMI slots offer the facility to add a DMI AVB port type and this also provides a DMI AVB Control panel where The AVB card sample rate and mode can be selected.

![Audio I/O panel with the DMI AVB Control dialog open, showing AVB Sample Rate and Network Mode](/figures/ref-p243-1.png)

![DMI AVB Control dialog: AVB Sample Rate set to 96000, Network Mode set to Redundant](/figures/ref-p243-2.png)

Firmware updates for DMI AVB are done via the AVB Update Tool.

Further information on DMI AVB is available in TN632 – DMI AVB User Guide.
