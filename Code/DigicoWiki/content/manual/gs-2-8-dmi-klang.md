# 2.8 DMI-KLANG

*DMI Cards — manual page 55*

With the DMI-KLANG card, 64 signals can be routed to the card and up to 16 immersive monitor mixes plus solo routed back to the console. The DMI card can be configured in the KLANG Control panel, found under the Cards & Sockets tab of the card's port in Audio I/O.

![KLANG Control panel: open it from Card Setup, set the Device Name, configure the IP Address and Subnet Mask, set the Control Ports, then apply the changes to the DMI card](/figures/gs-p055-1.png)

The DMI-KLANG card can be controlled from the console after being connected to the console's network and set up in the External Control panel.
