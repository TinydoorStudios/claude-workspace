# 3.2 Settings Pane

*Quantum Home — manual pages 59–60*

Click the bottom Settings pane to expand it.

- 

**File Browser: opens a standard File Explorer**

- 

Delete Startup Sessions: deletes the following start-up files:

o “D:\Quantum2\startup.ses" o "D:\Quantum2\_session.ses"

- 

Show All Windows: restores all open windows that have been minimised. System Information: see section on system information.

- 

Advanced Settings: see section on advanced settings.

- 

Power: opens a window with three buttons:

o Power Off: turns the console PC off. o Restart: reboots the console PC (does not reboot the engine or work-surfaces). o Cancel: closes the Power windows and returns to the main Quantum Home view.
