# 5.1 Quantum Home

*Chapter 5: Quantum Home — manual pages 218–224*

When the Master screen > System > Quit To Home button is pressed, the console application is closed and the Quantum Home interface can be used to adjust various system settings.

When the system is locked, Quantum Home automatically launches the Quantum application on start-up. When unlocked, the system can be configured.

### 5.1.6 Main Shortcuts

-

-

- 

**Surface CPU Upgrade**

-

- 

File Browser: opens a standard File Explorer.

### 5.1.7 Settings Pane

Click the bottom Settings pane to expand it.

- 

Quantum Test: launches the Quantum Test application.

- 

Delete Startup Sessions: deletes the following start-up files:

- “D:\Quantumx\startup.ses"

- "D:\Quantumx\_session.ses"

- 

Show All Windows: restores all open windows that have been minimised. System Information: see section on system information.

- 

Advanced Settings: see section on advanced settings.

- 

Power: opens a window with three buttons:

- Power Off: turns the console PC off.

- Restart: reboots the console PC (does not reboot the engine or work-surfaces).

- Cancel: closes the Power windows and returns to the main Quantum Home view.

### 5.1.8 System Information

Opens a window displaying general information about the system:

- 

General:

- PC Name: name of the console PC – the factory default name should contain the serial number

of the console.

- IP Address: static IP address of the console PC.

- App Version: version number of the Quantum 8 application.

- Home Version: version number of Quantum Home.

- System Version: version number of the overall system.

- 

Disks:

- C Drive: amount of free disk space on the C:\ drive.

- D Drive: amount of free disk space on the D:\ drive.

- Memory: amount of RAM on the console PC.

- 

BIOS:

- BIOS: version number of the console PC’s BIOS.

- Firmware: version number of the console PC’s board controller firmware.

- 

Save to File: click to save the system information to a text file. The saved file also contains the “locked/unlocked” state of the PC and a timestamp.

### 5.1.9 Advanced Settings

![Quantum Home (manual p.221)](/figures/ref-p221-1.png)

- 

Lock System Settings/Unlock System Settings: locks/unlocks the system and triggers a console PC reboot.

- Locked state: this is the “console mode” in which Quantum Home automatically launches the

Quantum 8 application at start-up.

- Unlocked state: “configuration mode” in which advanced settings and network settings are

enabled.

- 

Display Settings:

- External Screen: settings for the external monitor.

▪ Resolution: drop-down list of available screen resolutions for the external screen. ▪ Orientation: drop-down list of screen orientations:

- 

Landscape.

- 

Portrait.

- 

Landscape (inverted).

- 

Portrait (inverted).

- 

Disconnected: disables the external screen.

- Configure All: applies the external screen settings and reconfigures the master, left and right

screens. Once configured, Quantum Home identifies the screens, allowing for a visual confirmation of the new display configuration. Note that Quantum Home will require a restart after displays configuration, either by locking and rebooting the console or by a forced restart of Quantum Home when exiting the Advanced Settings menu.

- Identify Displays: pops up the display identification view on each screen highlighting the

current screen position.

### 5.1.10 Network Settings

Requires the system to be unlocked to apply new setting. If the system is locked, the current settings are displayed but cannot be changed.

![Quantum Home (manual p.222)](/figures/ref-p222-2.png)

![Quantum Home (manual p.222)](/figures/ref-p222-3.png)

- 

Console IP Address: shows the current IP address of the console, can be edited to apply a new console IP address.

- 

Subnet Mask: shows the current subnet mask of the console, can be edited to apply a new console subnet mask.

- 

Apply: applies the network settings (console and engine IP addresses and subnet mask).

- 

Lock & Restart: is enabled after network settings have been applied. Causes the console PC to restart and locks the system.

### 5.1.11 Keyboard Shortcuts

- 

Hold “Space” at start-up: boots to Quantum Home without launching the Quantum application.
