# DiGiCo Quantum 225 Wiki

Staff reference for the Quantum 225 at Memorial Hall and Fountain Square, the DMI cards in it (Dante 64@96, KLANG, Waves, MADI), and the stage I/O it talks to (DQ-Rack, MQ-Rack, A168D Stage). Type what you're trying to do in the search box at the top — every page, including the full DiGiCo manuals, is indexed.

Console software: **V22 (build v2242, June 2026)**. The reference manual mirrored here is Issue H (V20+); everything V22 added is in the [V22 release notes](/docs/v22-release-notes).

## Start here

- [How do I…](/how-to) — short task pages with screenshots: power up, load a session, patch a mic, ring out a monitor, save before you leave.
- [I/O, racks and DMI cards](/hardware) — what's plugged into what, how each card is set up, what the lights mean.
- [Console: Getting Started](/console) — DiGiCo's own walkthrough of the Q225 surface, screens and session basics.
- [Software Reference](/reference) — the complete SD & Quantum reference manual, one page per menu, with every figure.
- [DiGiCo documents](/docs) — release notes, tech notes, rack and card guides.
