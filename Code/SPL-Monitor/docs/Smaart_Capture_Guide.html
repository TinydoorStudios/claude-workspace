Smaart SPL Webviewer — Capture Guide

Goal: record a short sample of the live SPL/LEQ data so the dashboard can be built against the real format. Browser-only — nothing to install on the Smaart machine.

Before you start (on the Smaart PC, over your remote session)

  1. Confirm the version. Smaart Help > About — I need it to be v8.3 or newer (that's when the WebSocket API arrived). Tell me the exact version.
  2. Have SPL logging running with real audio present (music or pink noise) so the meters are actually moving — a frozen reading captures nothing useful.
  3. Enable the API: Options > Preferences > API → check Enabled. The status indicator should go green. Note the port (default 26000). Leave any password blank if you can, or tell me what you set.
  4. Open the webviewer in a browser on that same machine: go to http://localhost:26000 (swap in your port if you changed it). You should see live SPL numbers. If you get a blank page or nothing loads, stop and tell me — your v8 build may not serve the browser webviewer and we'll switch tactics.
Use a private/incognito window for the webviewer — Rational recommends it, since extensions can interfere with the API.

Method A — recommended  DevTools → HAR (captures everything in one file)

  1. On the webviewer page, open DevTools: F12 (or Ctrl+Shift+I).
  2. Click the Network tab. Tick Preserve log. Click the WS filter so it only shows WebSocket traffic.
  3. Reload the page (Ctrl+R) with DevTools open — this captures the connection from the very start, including the first commands the page sends.
  4. You should see one entry with status 101 (Switching Protocols). Click it → Messages tab to confirm frames are streaming (↑ sent, ↓ received).
  5. Let it run ~60 seconds with audio playing.
  6. Right-click anywhere in the Network request list → Save all as HAR with content (Edge/Chrome). Save the .har file.
  7. Send me that .har file. It contains the full exchange — the subscribe commands and all the SPL/LEQ data frames.

Method B — fallback  Copy a handful of frames by hand

If "Save as HAR" doesn't include the WebSocket messages on your browser version, just copy a few frames manually.

  1. DevTools → Network → WS filter → reload → click the 101 entry → Messages tab.
  2. Copy the first ~10 sent (↑) frames — these are the connect/subscribe commands.
  3. Copy ~20 received (↓) frames — these are the SPL/LEQ data. Click a frame to expand its full text.
  4. Paste both sets back to me (a screenshot of the Messages list also works in a pinch).

Method C — optional  Console snippet (bulk data, auto-download)

Handy for grabbing lots of data frames as a clean JSON file. Catches the live data reliably; for the connect commands still use Method A or B.

  1. On the webviewer page: DevTools → Console.
  2. Open capture/smaart-capture-snippet.js, paste the whole thing into the console, press Enter.
  3. Wait ~60 seconds with audio, then type splDump() and press Enter. A smaart-capture-*.json downloads. Send it to me.

Whatever you send — HAR, pasted frames, or the JSON dump — I'll read the real message format from it and wire the dashboard to it exactly. While you do this, I'll build the dashboard against a simulator so there's a working UI waiting when the capture comes back.
