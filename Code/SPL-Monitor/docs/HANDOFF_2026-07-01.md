## What We Did

Added a live "tonight's show + engineer" banner to the SPL Monitor dashboard and the same
information to the nightly summary email, sourced from three of Brian's Google Sheets (all public
"publish to web" CSVs — no API key needed):

1. **Crew schedule** — main day-by-venue grid. FSQ block = columns G–J (date/DOTW/event/mix-code).
2. **Crew code cross-reference** — second tab, same spreadsheet, mix-code → full name.
3. **Band booking sheet** — separate spreadsheet, Date/Location/Performer, filtered to
   `Location == FSQ`. Gives the real band/event name when the schedule sheet just has a
   placeholder ("Reggae (4-11)", "TBD", etc.).

Verified live against 7/1/26 real data before writing any code, then again after each change:
schedule sheet said `3cdc Programming (4-10) — Potentially watch party, TBD` / mix code `CK`;
band sheet resolved that to **"World Cup Watch Party : DJ Steve"**; code sheet resolved `CK` to
**Colin Kombrinck**. Both matched at every verification step.
