# _inbox — drop files here for Nyquist

Put anything you want me to look at in this folder: docs, PDFs, images, spreadsheets,
stage plots, screenshots, exports. Then just tell me what you dropped (or say "check the
inbox") and I'll read it.

- Lives at `~/Documents/Claude/_inbox` — top of the workspace so it's easy to find.
- Files copied here are real local files, so I can open them immediately.
- **Dropbox gotcha:** if you drag something straight from a Dropbox folder and it lands as a
  0-byte placeholder, right-click → Make Available Offline first (or just copy the file in
  rather than moving a link).
- I won't delete anything here unless you ask. Old files are fine to leave.
