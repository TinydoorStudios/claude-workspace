DROP FOLDER — DPA 4099 on the Yamaha C3 (reference photos)
==========================================================

Put real reference photos for the C3 deep-dive in THIS folder.

How to use:
  1. Save or screenshot images (DPA pages, Sound On Sound, your own rig shots,
     anything) and drop the files in here. Accepted: jpg, jpeg, png, webp, heic, tiff.
  2. (Optional) add captions + credits. Two ways:
       a) captions.tsv  — one line per image, TAB-separated:
              filename<TAB>caption<TAB>credit
          (a starter captions.tsv is in this folder — edit it)
       b) a sidecar text file next to an image, same name + .txt, holding:
              caption | credit
     If you skip captions, the filename is used as the caption.
  3. Tell me "embed the C3 reference photos" (or re-run the C3 build) and the
     images appear, cropped/captioned/credited, on the Reference Photos page of
     DPA-4099-on-Yamaha-C3.pdf.

Order: images appear in filename order. Prefix with 01_, 02_, ... to control it.

Tip: phone photos and screenshots are auto-rotated upright (EXIF aware).
