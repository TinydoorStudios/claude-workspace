# Mic Photo Manifest

Drop each mic's product photo as the **full-size** file below into its folder, then run
`python3 make_thumbs.py` to auto-build the thumbnails, then publish. Pages + gallery render
the moment the files exist. Source URL is the manufacturer page to grab the shot from.
