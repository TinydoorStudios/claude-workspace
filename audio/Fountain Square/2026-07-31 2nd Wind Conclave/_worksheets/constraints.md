# Constraint card — 2nd Wind Conclave · FSQ · 2026-07-31

Written from the skill file read in full at the start of this build (2026-07-26).

## The numbers
- **Whole dB only.** No half-dB anywhere. Round up.
- **Cuts before boosts, always.** Find the problem, cut it, then decide if a boost is still needed.
- **Vocals: cuts only.** Every genre, no exceptions. This is feedback control, not taste.
- **No high-shelf band unless Brian asks.** He hasn't. B4 goes bell unless there's a reason.
- **Band numbering matches the console: B1 = LF … B4 = HF.** Document order is
  HPF → LPF → B4 → B3 → B2 → B1.
- **Ranges:** cuts −4 to −7 dB tight Q (1.5–2.0), boosts +3 to +6 dB on non-vocal sources.
- **FSQ / outdoor override:** cuts run DEEPER — **−6 to −9 typical, up to −10 on mud/box.**
  Torn between two depths, take the deeper one. HPF higher. Be decisive.

## The flags
- **Ribbon = NO 48V, in red.** (No ribbons on this list — nothing to flag.)
- **TOUR gear (⚑) is never swapped and never locker-forked.**
- **Locker fork on every mic'd input.** DI and XLR line feeds are EXEMPT — no capsule, no fork.
  One alternative max, three-sentence reason (the win with a number · what it changes ·
  the honest cost), availability-checked. **An unanswered fork blocks the build.**

## The venue
- **FSQ ch 10 is RESERVED — SNARE PL8 reverb return, not an input.**
- **Overheads are STEREO on fader 9** — both OH mics on that one fader. Never split 9/10.
- **House wireless faders: FSQ 33 / 34 / 35 / 36 = Wireless 1–4.** A band input whose mic
  names a unit ("Wireless 2", "W58 2") mults the receiver — both rows, same source port,
  ride digital trim on the mult. A bare "W58" with no unit number = stop-and-ask.
- Outdoor: no room gain, no boundary help. Wind + ambient noise floor tighten GBF margins.

## The process
- **Research floor:** every unique instrument × mic unit gets a fresh web pass this show.
  No unit is researched until I can state ≥1 quantitative capsule fact (a frequency AND a
  dB value) with an external source named. KB is the cross-check, never the source.
- **Capsule gate:** before writing any boost, state what the capsule already bakes in near
  that frequency. Boost inside a baked peak = wrong; trim instead.
- **Reconcile verdict: one word per unit — AGREE / DISAGREE / THIN.** Written before numbers.
  DISAGREE/THIN → question round with the (a) research / (b) KB / (c) research+update-KB fork.
- **One batched question round** before any EQ commits. Locker forks first.
- **Genre verified with named evidence before research runs.** Split evidence = ask immediately.
- **Equipment (amp/cab, drum sizes, strings, pickups) rides the instrument layer** with the
  same research floor as a mic.
- **Per-unit TRACE line** closing each research_summary: base · equip · genre · artist · venue,
  a value or an explicit "no change" per layer.
- **Reverbs anchored to factory** — Seventh Heaven Pro preset names verbatim, every value
  marked (factory) or (from X factory). Required section, FSQ included.
- **Pacing rule:** research lands visibly before any final numbers appear.
